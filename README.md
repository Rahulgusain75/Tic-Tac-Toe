# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML**, **CSS**, and **JavaScript**. Two players can take turns marking the spaces in a 3×3 grid. The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row wins the game.

---

## 🕹️ Features

- 🎯 Two-player turn-based gameplay
- ✅ Win and draw detection
- 🔄 Restart game functionality
- 🎨 Clean and responsive UI with CSS
- 💡 Simple and lightweight — no frameworks
